### Gitleaks via pre-commit
*taken from https://github.com/gitleaks/gitleaks#getting-started*
Mac
Install gitleaks using your package manager of choice (I use brew)
```shell
brew install gitleaks
```
Install precommit
```shell
brew install pre-commit
```
This will take a few minutes to initalize.

Auto-update to latest version:
```shell
pre-commit autoupdate
```

And finally, install
```shell
pre-commit install
```
